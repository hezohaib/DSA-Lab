# Data Structures Lab (C++)

This repository contains my lab work and assignments for the Data Structures course at **COMSATS University Islamabad, Attock Campus**. All codes are written in pure C++ without using any STL containers.

## Lab 01 - Array List (1st Week)
Custom Array List implementation using a simple structure. Includes basic operations such as:

- Insert at end / beginning
- Delete from specific position
- Display list
- Pointer-based traversal for finding minimum, maximum, sum, and median
- Calculation of general average and special average
- Finding the closest value and performing required modifications

## Lab 02
Additional practice tasks related to Array List and basic pointer operations.

Assignment 01 extends this with raw pointer traversal to compute:

Min, max, sum, median
General average vs. special average (min + median + max / 3)
Closest value to the special average
Final score combining all three distances
Deletion of the closest element and re-insertion of the rounded special average
